# Work

A short English page about the language-learning work around Yibu and AngolMag, published so the sites and documents can be opened from any device — including Safari 9 on a first-generation iPad mini.

Live: https://guywitharicecooker.github.io/work/

- `index.html` — this page (no build step, no JavaScript)
- `sketch.html` — the Yibu paid-product sketch in plain HTML (the main way to read it on older Safari)

The pages use a simple block layout, system fonts, and static colours, with dark mode only as a `prefers-color-scheme` enhancement.
